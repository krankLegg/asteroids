#### About:
A simple asteroids game

#### Dependencies
- Python 3
- pygame

#### Running the game:
- install dependencies
- create the python virtual environment: `python3 -m venv .venv`
- load the python virtual environment: `source .venv/bin/activate`
- start the game: `python3 main.py`

#### Game Controls

| Key | Control |
| --- | --- | 
| w | forward | 
| s | backward | 
| a | turn right | 
| d | turn left | 
| spacebar | shoot | 
| | |
